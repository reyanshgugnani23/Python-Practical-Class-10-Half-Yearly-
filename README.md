# Python Practical – Class 10 Half-Yearly

Programs from **BASICS OF PYTHON PROGRAMMING(1).pdf** used for Python Programming at Amity International School, Sector-46, Gurugram.

## Contents
- `examples/` – Python code examples from the practical material
- `if_else/` – conditional-statement practical programs
- `loops/for/` – For-loop practical programs
- `loops/while/` – While-loop practical programs
- `patterns/` – pattern-printing programs
- `cbse_python_manual/` – CBSE Python Content Manual reference: syntax, sample study programs, data types, operators, conditions, loops, lists/tuples, packages and NumPy

## CBSE Python Manual Reference
The `cbse_python_manual/` folder is based on the CBSE **Python Content Manual** published as support material for the Artificial Intelligence curriculum. It includes a syntax cheat sheet and concise original examples aligned with the manual's topics rather than reproducing the textbook verbatim.

Official source: https://cbseacademic.nic.in/web_material/Curriculum21/publication/secondary/Python_Content_Manual.pdf

The practical programs remain separate from the CBSE reference material so that the repository can be used both for school practical preparation and as a Python syntax/reference guide.

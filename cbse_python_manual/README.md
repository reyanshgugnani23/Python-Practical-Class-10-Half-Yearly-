# CBSE Python Content Manual – Class 10 Reference

Reference section based on the **CBSE Python Content Manual** published as support material for Artificial Intelligence. The manual covers Python from algorithms/flowcharts through variables, data types, operators, input/output, lists, tuples, conditions, loops, packages and NumPy. [CBSE source](https://cbseacademic.nic.in/web_material/Curriculum21/publication/secondary/Python_Content_Manual.pdf)

## Included
1. Python statements, comments, identifiers and variables
2. Data types and collections
3. Input, output and type conversion
4. Operators
5. Lists and tuples
6. `if`, `if-else`, `if-elif-else`, nested `if`
7. `for` and `while` loops
8. Packages and import syntax
9. NumPy basics and array operations

The examples in this folder are concise study/reference examples aligned to the concepts and syntax taught in the manual. They are intentionally written as short original examples rather than reproducing the textbook verbatim.
